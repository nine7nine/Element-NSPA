Lulada Documentation

Design and technical reference for Lulada — a Winelib / Wayland DAW built on Element and Wine-NSPA.

Lulada is a fork of Element extended into a full DAW and built as a winelib application: native Linux code that hosts Win32 VST2 / VST3 / CLAP plugins in-process through Wine-NSPA at realtime priority, with an experimental Wayland windowing path. On top of Element's modular graph core it adds a tracker, a piano-roll, an Ableton/Bitwig-style Session View, a linear Arrangement timeline, an FT2-style sampler, and a sample-accurate automation engine. These pages document each subsystem from its real implementation.

  • Winelib Runtime CORE

  • JUCE-NSPA CORE
    The JUCE fork: the winelib plugin-hosting module, the per-plugin Win32 worker that keeps plugin code on a thread it recognises, librtpi priority-inheriting sync, and plugin-editor embedding.
  • Threading & RT Safety CORE
    The SCHED_FIFO priority ladder, the three wait-free hand-off patterns (SPSC FIFO, COW snapshot, PI signalling), the parallel render pool, and the hazards the discipline defends against.

  • Graph Engine CORE
